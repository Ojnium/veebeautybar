# VeeBeautyBar - Affordable Luxury. Timeless Beauty.

## 🌟 Overview

VeeBeautyBar is a professional beauty studio based in Abuja, Nigeria, specializing in lash extensions, brow services, and beauty training. This website showcases our services, brand identity, and provides easy booking options.

**Live Demo:** [veebeautybarr.ng](https://veebeautybarr.ng)
